# Security Policy for Master Math

## Supported Versions

Kami sangat menyarankan untuk selalu menggunakan versi terbaru dari Master Math untuk mendapatkan pembaruan fitur dan perbaikan keamanan.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Kami menghargai kontribusi komunitas dalam menjaga keamanan aplikasi **Master Math**. Jika Anda menemukan kerentanan keamanan, harap ikuti langkah-langkah berikut:

1.  **Jangan membuka issue publik** untuk melaporkan kerentanan keamanan.
2.  Laporkan kerentanan melalui fitur [Private Vulnerability Reporting](https://github.com/IndraMahayana/Master-Math/security/advisories/new) di GitHub jika tersedia.
3.  Atau, Anda dapat menghubungi pengelola repositori secara langsung melalui email atau media sosial yang tertera di profil GitHub.

### Apa yang Akan Kami Lakukan:
*   Kami akan meninjau laporan Anda dan memberikan respon awal dalam waktu 48-72 jam.
*   Kami akan memberikan estimasi waktu perbaikan setelah kerentanan dikonfirmasi.
*   Setelah perbaikan dirilis, kami akan memberikan kredit kepada pelapor dalam catatan rilis (kecuali jika pelapor meminta anonim).

Terima kasih telah membantu menjaga keamanan **Master Math**!
